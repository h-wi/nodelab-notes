# nodelab 개념 노트

nodelab 프로젝트(개인 서버에서 Bitcoin Core Signet 노드를 Kubernetes로 운영하며 시스템 엔지니어링을 배우는 실습)의 선제 개념 노트입니다.

- 사이트: https://h-wi.github.io/nodelab-notes/
- 내용: 두 탭으로 나뉩니다.
  - Solana: 서버 하드웨어(CPU topology, NUMA, NVMe, RAID), Solana 기본(slot, ledger, snapshot, account, RPC), 리눅스 운영
  - Bitcoin 노드랩: Linux, 컨테이너, Kubernetes, 네트워크, 저장장치, Bitcoin Core, 성능 측정
- 갱신: 프로젝트의 학습 진행에 맞춰 매일 자동으로 갱신됩니다.
